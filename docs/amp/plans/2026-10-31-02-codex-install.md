# Phase 02 — amp for Codex: Implementation Plan

> Executed by amp:build (one amp:implementer per task, reviewed per task). Checkbox steps track progress.

**Goal:** Ship amp as both a Claude Code plugin and a Codex plugin plus agents. Both are rendered
from one `src/` with per-tool blocks, so each tool reads text optimized for itself.

**Spec:** `docs/amp/specs/2026-10-31-02-codex-install.md`. It is the binding authority, and
conflicts resolve against it.

**Branch:** `feature/02-codex-install`

**Architecture:**

- `scripts/render` (bash + awk) turns `src/skills` and `src/agents` into the Claude tree
  (`skills/`, `agents/`) and the Codex tree (`codex/skills/`, `codex/agents/amp-*.toml`), with
  `--check` for drift.
- `codex/install` copies the agent TOMLs into Codex's agents directory and writes
  `amp-install.json`, which holds the model pins and the version.
- `.codex-plugin/plugin.json` points Codex at `codex/skills` and sets `"hooks": {}`.

**Tech stack:** bash (Git Bash on Windows), POSIX awk, sed, diff. The Claude Code hooks module
(`hooks/register.tsx`) is unchanged.

**Dispatch skills:** none (the repo has no CLAUDE.md). `amp:lean` always.

## Global Constraints

- **Rendered trees are outputs and are never edited by hand.** These are `skills/`, `agents/`,
  `codex/skills/` and `codex/agents/`. Every content change goes to `src/` and is followed by
  `bash scripts/render`.
- **Markup** (spec §5.1), processed in `.md` files only:
  - line markers exactly `<!-- claude -->`, `<!-- /claude -->`, `<!-- codex -->`, `<!-- /codex -->`;
  - spans `{{claude: TEXT}}` and `{{codex: TEXT}}`;
  - file variants `NAME.claude.EXT` and `NAME.codex.EXT`.
- **Codex-only rewrites:**
  - `amp:(implementer|reviewer|checker|scout)` → `amp-\1`
  - `${CLAUDE_PLUGIN_ROOT}/skills/` → `<skills>/`
  - `${CLAUDE_SKILL_DIR}/` → `` (removed)
  - `/amp:` → `$amp:`, because Codex invokes skills with `$name`. This is a ruling.
  - skill frontmatter is reduced to `name` and `description`
- **Agent TOML** (spec §5.2):
  - header `# Generated by scripts/render from src/agents/<name>.md. Do not edit.`
  - `name = "amp-<name>"`, a basic-string-escaped `description`, and a
    `developer_instructions = '''…'''` block
  - **no** `model` and **no** `model_reasoning_effort` line
- **Installer flags:** `--project`, `--reviewer|--implementer|--checker|--scout M`, `--uninstall`.
  M must match `^[A-Za-z0-9._:/-]+$`. Exit codes: 2 for usage or an invalid model, 1 for a
  missing git repository or missing agent files.
- **`amp-install.json`:**
  `{"version": "<v>", "models": {"reviewer": …, "implementer": …, "checker": …, "scout": …}}`,
  with each value a quoted string or `null`.
- **Version** is `1.2.0` in `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`.
- **Line endings:** `.gitattributes` is `* text=auto eol=lf`.
- **Script modes:** this checkout has `core.filemode=false`. After every render, and for every new
  script, run `git add -A` and then `git update-index --chmod=+x` on each script:
  - `scripts/render`, `scripts/test`, `codex/install`
  - `skills/build/scripts/*`, `codex/skills/build/scripts/*`, `src/skills/build/scripts/*`

  The `modes` test checks the result in `git ls-files -s`.
- **`scripts/test` runs from anywhere:** it resolves the repo root from its own path, invokes every
  script by an absolute path, and greps with `-F` (case-sensitive).
- **Verify:** `bash scripts/test && claude plugin validate --strict . && claude plugin test .`

## Review Focus

1. Windows Git Bash: paths with spaces, CRLF, no false drift. This is pinned in Task 1 by
   rendering from a root containing a space.
2. TOML validity for `"`, `\` and non-ASCII. A `'''` is rejected. Pinned in Task 1.
3. Leaks between trees. Pinned in Task 3b's `leaks` test.
4. `"hooks": {}` override. Pinned in Task 2 with a manifest assertion.
5. The stale-agent version check in phase preflight. Pinned in Task 3a, whose test asserts the
   Codex phase text names `version` and `.codex-plugin/plugin.json`. Task 2 tests the installer
   writing `version`.
